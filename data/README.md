# Your own data

Put Turtle files describing your own AI systems, risks and applied controls in
this folder (see `examples/` for the pattern). They are loaded automatically by
`scripts/asgo.py validate`, `query` and `query-all`.

`*.ttl` files here are **git-ignored by default**, because an AI inventory is
usually confidential. Remove the rule from `.gitignore` if you want to version it.
